# Narrow bridge

Units are meters, +X is forward, and +Z is up. The bridge is 2.8 m long and 0.43 m wide, without rails, over a 0.16 m drop. The Jumper preview-pose collision envelope is 0.3848 m wide, leaving about 22.6 mm of static clearance per side when centered. This does not validate a dynamic gait.

Challenge: enter the bridge from `start`, stay on it until `exit`; contact with the basin below counts as failure as determined by the app. The package has no controller or automatic scoring.
