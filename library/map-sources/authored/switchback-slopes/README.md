# Switchback slopes

Three slopes are 0.70 m wide and 3.60 m long horizontally, each rising 0.45 m at about 7.13°, for a final height of 1.35 m. Slopes are full-volume convex wedges with solid collision. Platform edges meet slope edges flush. The 0.84 m wide platforms allow turns between opposite-facing slopes.

Order: `start` → `ramp_0` east → `turn_1` → `ramp_1` west → `turn_2` → `ramp_2` east → `exit`. The app checks waypoint order, falls, and timing; the map supplies no validated gait.
