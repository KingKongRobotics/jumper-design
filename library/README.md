# Content library

The complete collection contains 16 skins and 13 maps. Formal files live directly in skins/ and maps/, with indexes and embedded thumbnails. The main README highlights six selected examples; it is not the full collection.

Existing public-edition original-robot packages are retained. Added packages preserve their original bytes, defaults and license metadata. See the root NOTICE.md for license scope; repository Apache-2.0 does not automatically relicense third-party content. Printing files remain separate and are not included in this initial project.
