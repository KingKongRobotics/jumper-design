# Initial public release

This repository starts with a new public history. The internal development repository and its history are not included.

## Included

- Apache-2.0 workflow code, standards and English documentation.
- Current Jumper display baseline and Jumper Original skin.
- Park Pump Track, Narrow Bridge, Shelf Maze and Switchback Slopes with the original robot embedded.
- Source snapshots for those authored environments and robot-free embedded thumbnails.

## Excluded

Historical print deliveries, manufacturing CAD bundles, previous robot baselines, website code, credentials and internal Git history.

## Local verification

The initial public candidate passed 163 tests and 90 subtests on Windows/Python 3.12. All five packages passed native MuJoCo validation. English and publication-pattern scans passed. Environment visual assets and map thumbnails were compared byte-for-byte with the source releases; README images match the embedded images. The wheel includes Apache-2.0 metadata and license notices.

Three MuJoCo attachment warnings were emitted during tests; the native attachment tests passed. No new controller, physical-fit or end-to-end browser simulator certification is claimed. GitHub Actions provides separate Linux/Python 3.10 and Windows/Python 3.12 jobs; configuration does not imply those remote jobs have already passed.
