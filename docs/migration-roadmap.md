# Capability boundaries

Implemented: package parsing and integrity checks; complete-robot display export; scene compilation and attachment; native MuJoCo loading checks; indexed library publication; versioned visual and physical contracts.

Not provided as automatic end-to-end services: AI modeling accounts, generic geometry fitting and hollowing, print engineering certification, physical installation, learned controller training, task scoring or community website deployment. The physical workflow records evidence and must not label registration alone as verified engineering.

Legacy protocol readers remain available, but old mechanical profiles and historical print libraries are intentionally absent from the public sample set.
