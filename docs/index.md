# Documentation

Use these guides by task:

- [Quick start](quickstart.md): install the tools, inspect package commands, verify an example, and export a map.
- [Content package protocol](content-packages.md): `.skin` and `.map` formats, versions, manifests, validation, import, and repacking.
- [Content release rules](content-release-rules.md): requirements for published examples and package previews.
- [Workflow](workflow.md): appearance, environment, and physical-shell workflows and their acceptance gates.
- [Engineering and acceptance](engineering-and-acceptance.md): digital evidence, visual review, printing, and physical-fit boundaries.
- [Simulation](simulation.md): simulation dependencies, assembly outputs, and loading checks.
- [Architecture](architecture.md): package and compiler organization.
- [Authored challenges](authored-challenges.md): supported scene challenge descriptions.
- [Scene upstreams](scene-upstream.md): provenance and handling of imported scenes.
- [Platform packs](platform-pack.md): robot platform profiles and imported platform assets.
- [Web appearance standard](web-appearance-standard.md): visual declarations and rendering expectations for supported consumers.
- [Providers](providers.md): boundaries around optional external services.
- [Licensing](licensing.md): project, third-party, and generated-content terms.

The repository root [README](../README.md) describes capabilities and links to the public examples.
